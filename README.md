# sam-record-processor-go

测序比对记录（SAM 文本格式）处理工具包与命令行程序。面向下游变异检测与
质控：解析校验、坐标排序、多路归并、重复标记、区间覆盖视图。全部基于本地
文件，不依赖外部服务。

## 构建与测试

```sh
go build ./...        # 构建
go test ./...         # 运行全部自动化测试
go build -o samproc ./cmd/samproc
```

## 命令行

```
samproc sort     -i in.sam -o out.sam [--mem 256M] [--threads N] [--workdir DIR] [--keep-work]
samproc merge    -o out.sam [--mem 256M] [--threads N] [--workdir DIR] in1.sam in2.sam ...
samproc dedup    -i sorted.sam -o out.sam
samproc index    -i sorted.sam
samproc coverage -i sorted.sam --ref NAME --start N --end N [--include-dups]
samproc validate -i in.sam
```

`--mem` 接受字节数或 `K`/`M`/`G` 后缀（如 `512M`）。

## 解析与校验规则

解析器覆盖 SAM 全部 11 个必需列、全部标志位与 CIGAR 操作
（`M I D N S H P = X`）以及辅助标签（`TAG:TYPE:VALUE`，类型
`A i f Z H B`）。以下情况报错并定位到具体行号与字段，绝不静默接受：

- 结构错误：字段不足 11 列、空行、记录之后出现头部行、非法 FLAG/MAPQ/
  POS/PNEXT/TLEN 数值、非法 CIGAR 字符或长度为 0 的操作、SEQ 含非法字符、
  QUAL 含不可打印字符、辅助标签格式错误。
- 引用未声明参考序列：RNAME 或 RNEXT 未在 `@SQ` 中声明；`@SQ` 缺少 `SN`
  或 `SN` 重复。
- 标志位自相矛盾：0x2/0x8/0x20/0x40/0x80 在未配对（0x1 未置位）时置位；
  0x40 与 0x80 同时置位。
- 语义矛盾：已映射记录缺少 RNAME/POS/CIGAR；无参考序列的记录 POS 非 0；
  QUAL 与 SEQ 长度不一致；CIGAR 消耗的查询碱基数与 SEQ 长度不一致。

## 排序规则

- 排序键：参考序列名的**字典序**（`chr10 < chr2`），再按 1 起始坐标升序。
- 未映射且无可用坐标的记录（RNAME 为 `*`）统一排在末尾。
- 同键记录按整行字节序裁决，排序是全序的：相同输入与配置下输出逐字节一致，
  与并发度无关。
- 输出头部重写为 `@HD ... SO:coordinate`，其余头部行保留。

内存超限时自动外排：输入按块读入（块内存 ≈ `--mem / (threads+1)`），排序后
落盘为临时 run，再多路归并。归并扇入数由 `--mem` 推导（每路约 2MB 缓冲，
最少 2 路），路数不足时进行多轮归并，因此任意小的内存上限都能完成排序。

## 归并规则

- 输入必须是坐标有序 SAM（逐输入校验有序性，违例报错）。
- 记录不丢失、不重复、不改写（未修改的记录逐字节透传原始行）。
- 头部取各输入的并集：重写 `@HD SO:coordinate`，其余行按首次出现顺序去重。
- 输出满足排序约束，可继续作为后续归并的输入。

## 重复标记规则

- 判定键：
  - 配对且 mate 已映射的记录：两端比对起点（RNAME:POS 与 RNEXT:PNEXT，
    `=` 规范化为自身参考名）与两端方向（0x10、0x20）。
  - 其他记录（单端、或 mate 未映射）：自身起点与方向。
- 不参与判定也不被标记：未映射（0x4）、次级（0x100）、补充（0x800）。
- 每个重复集合中保留碱基质量总和（Phred 之和）最高的一条为代表；质量相同
  时按记录名字典序、再按整行字节序取舍，结果确定。其余记录置位 0x400。
- 输入须为坐标有序；实现按坐标分组流式处理，内存占用以单坐标组的记录数
  为界。

## 覆盖视图规则

`coverage` 对区间 `[start, end]`（1 起始、闭区间）逐位点输出 TSV：

```
参考名  坐标  深度  覆盖记录数  插入数  观测明细
chr1    105   2     2           0       A:40:+,T:20:-
```

- **深度**：该位点的碱基观测数。**覆盖记录数**：跨越该位点的记录数（含纯
  缺失跨越）。因此「深度为零但被记录跨越（缺失事件）」与「区间内无任何
  记录」可区分：前者深度 0、覆盖数 > 0，后者两者皆 0。
- **观测明细**：逗号分隔的 `碱基:质量:方向`，方向 `+`/`-` 来自 0x10；
  碱基按 SEQ 原样报告（反向不互补）。
- CIGAR 语义展开：`M/= /X` 产生碱基观测；`I` 计入前一位点的插入数；
  `D` 计为覆盖但无碱基；`N` 既不计深度也不计覆盖；`S/H/P` 不产生观测。
  插入与缺失不影响后续位点的参考对应关系。
- 未映射、次级、补充记录一律不计；重复标记（0x400）记录默认不计，
  `--include-dups` 开启后计入。
- 查询以有界内存完成：只驻留与当前位点重叠的记录。`samproc index` 生成的
  线性索引（`.sami`，16kb 窗口，含各参考序列最大比对跨度）可把区间查询
  加速到近似随机访问；索引失效（文件大小或修改时间变化）时自动回退为
  全文件顺序扫描，结果一致。

## 并发

`--threads N` 控制排序分块与归并轮次的并发度。分块边界与归并计划只取决于
输入与配置，任何并发度下输出逐字节一致（测试覆盖）。

## 中断与重启

- 中间 run 写入工作目录（默认 `<输出>.work/`）：先写临时文件、fsync、再
  原子改名，完成后登记到 `manifest.json`（含 SHA-256 与大小）。
- 重跑相同命令时，清单中校验通过的 run 直接复用；损坏条目、孤儿临时文件
  与配置不符的旧状态一律清除后重做。最终输出同样原子落盘，不存在半写出
  的可见状态。重跑结果与一次完成逐字节一致。
- `--keep-work` 保留工作目录以便复用与排查；默认成功后清理。

## 资源上限

- `--mem`：排序块与归并扇入的近似内存预算（默认 256MB）。记账按记录原始
  行字节加固定结构开销估算，属于工程近似而非精确硬顶；单条记录始终可
  处理。
- 归并每路约 2MB 读缓冲；覆盖查询内存以区间实际深度为界。

## 测试

`go test ./...` 覆盖：非法输入定位、超内存约束下的外排正确性、并发与串行
输出一致性、多路归并与再归并、重复标记（配对/单端/质量取舍/并列裁决/排除
项）、覆盖视图（CIGAR 展开、零深度与无记录区分、重复开关、索引与全扫描
一致性）、中断恢复（注入故障后续跑、损坏 run 重建、残留清理）。

注入故障用于测试：环境变量 `SAMPROC_FAIL_AFTER_RUNS=N` 在第 N 个 run 落盘
后使排序/归并失败。
